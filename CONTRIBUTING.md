# Contributing

Thanks for your interest in contributing! Please follow these simple steps:

- Fork the repository and create your branch from `main`.
- Write clear commit messages.
- Ensure pages build and run locally: `npm install && npm start` then open http://localhost:3000.
- Avoid committing secrets (API keys). Use placeholders.
- Open a Pull Request with a clear description of changes and screenshots if UI changes.

Issues are welcome for bugs and feature requests.
